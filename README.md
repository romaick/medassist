# МедАссистент

Поликлинический офлайн-прототип для Windows: структурированный приём, анамнез, осмотр и редактируемый черновик врачебной записи. Версия 0.5.1.

В 0.5.1 исправлены обновление даты и счётчиков при вводе, переход к редактированию сформированного текста и повторная загрузка данных после восстановления в другом окне. Проверены первичный и повторный приём на вымышленных данных, больничный, ручные правки и резервные копии. Формат сохранений не изменён.

Используйте только демонстрационные, вымышленные данные. Клинические протоколы и нормативные формы Беларуси не реализованы. Программа не назначает лечение и не оформляет листки нетрудоспособности.

Текущая разработка относится к поликлиническому режиму. Стационарный режим запланирован отдельно и пока не доступен.

## Запуск

Скачайте исходники репозитория через Code → Download ZIP, распакуйте и откройте `medassist/Start-MedAssist.cmd`. Установленный Edge или Chrome откроет приложение в отдельном окне. Дополнительные библиотеки и интернет для приёма не нужны.

Один раз откройте `medassist/Pin-MedAssist.cmd`: он создаст ярлыки `MedAssist` и `MedAssist Update` на рабочем столе. Сохраняйте постоянную папку приложения.

## Работа с осмотром

В новом приёме поля пусты. Кнопка «Осмотр без особенностей» заполняет 27 вариантов по нажатию. Любой пункт можно изменить или очистить. При замене отличающихся результатов требуется подтверждение. Показатели, уточнения и ручной черновик сохраняются; выбранные признаки проверяет врач.

Кнопка у названия каждого раздела заполняет только его признаки. Рядом с массой и ростом автоматически вычисляется ИМТ; заполненный результат включается в новый черновик. Дата повторного приёма расположена после больничного и завершает запись.

## Обновление

Нажмите **«Проверить обновления»** в левом меню. Браузер может попросить разрешить открытие окна обновлятора. После проверки новая версия устанавливается по подтверждению. `MedAssist Update` и `medassist/Update-MedAssist.cmd` остаются запасным способом. Перед установкой сохраните JSON через «Помощь и данные» → «Резервная копия» и закройте окна приложения.

Кнопка подключается при запуске через `Start-MedAssist.cmd`. Для прежних установок 0.3/0.4 нужны два новых файла: `Start-MedAssist.cmd` и `updater/Register-UpdateLink.ps1`, размещённые в той же папке программы. Обычный пакет обновления не заменяет файлы запуска. [Однократное подключение и блокировка скачанных файлов Windows](medassist/START-HERE.txt).

Пакет берётся из `release/medassist-update.json` этого репозитория. Повторно скачивать архив и распаковывать его вручную не нужно. Обновление заменяет только файлы `medassist/app`, сохраняя прежний адрес локального приложения и копию старых файлов. После прерывания повторный запуск обновления восстанавливает целостную папку.

Записи находятся в локальном хранилище браузера. Пакет обновления не содержит приёмов, и обновлятор не отправляет их на сервер. Перед сменой папки или браузера нужен экспорт JSON. Полная инструкция: [START-HERE.txt](medassist/START-HERE.txt).

## Проверки и устройство

Приложение: HTML/CSS/JavaScript без сторонних библиотек. Обновлятор: встроенный Windows PowerShell 5.1. Он проверяет HTTPS, размер, версии, список файлов и SHA-256; подпись издателя не реализована. Политики Windows не меняются. Если система запрещает сценарий, обычный запуск программы остаётся доступен.

Проверки из корня репозитория:

```text
node --test medassist/tests/core.test.cjs
powershell.exe -NoProfile -File medassist/tests/update.test.ps1
powershell.exe -NoProfile -File medassist/tests/update-link.test.ps1
```

Node нужен только разработчику для проверок и сборки пакета обновления.

Для выпуска следующей версии разработчик меняет номер в `app/version.json` и интерфейсе, проверяет изменения, затем выполняет `node release/build-update.cjs` и публикует исходники вместе с пакетом. Формат обновления 1 поддерживает данные схемы 2. Изменение обновлятора или схемы данных требует отдельного решения о совместимости.
