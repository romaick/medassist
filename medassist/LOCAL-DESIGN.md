# Medasist 0.23.0: интерфейс для Windows

С 0.31.0 действует оформление «Светлая карта» (см. ARCHITECTURE.md): меню разделов — горизонтальная строка сверху, слева — колонка последних карточек пациентов, версия — внизу этой колонки. Описанный ниже запуск и порядок работы прежние.

Выпуск 0.23.0 от 21 октября 2026 года продолжает существующий МедАссистент 0.22.0. При установке через штатный канал обновлений остаются прежняя папка, ярлык и схема локальных данных. Версия указана внизу левого меню.

## Запуск

1. Откройте `Start-MedAssist.cmd` в этой папке. Установленный Microsoft Edge или Google Chrome откроет приложение отдельным окном.
2. На экране выбора раздела нажмите «Поликлиника» (или Enter). На рабочем столе нажмите «Открыть вымышленный пример». Появится учебная карточка «Анна Тестовая · демо» с заполненными демонстрационными полями.
3. Пройдите разделы приёма, затем откройте «Запись». Поля диагноза и рекомендаций заполняет врач. «Сформировать черновик» собирает текст из введённых сведений.
4. Проверьте текст и при необходимости отредактируйте его. «Отметить: проверено врачом» требует подтверждения. Доступны копирование, скачивание `.txt` и завершение приёма.

Альтернативный запуск: откройте `app/index.html` в Edge или Chrome. Для обычной работы сервер, Node.js, установка библиотек и интернет не нужны. Запуск через `Start-MedAssist.cmd` также настраивает существующую кнопку обновлений.

## Что изменилось

- Разделы приложения расположены слева; сверху доступны контекст, поиск и часы. На узком экране меню прокручивается по горизонтали.
- С 0.24.0 при запуске открывается выбор раздела: «Поликлиника», «Стационар» («В работе», недоступен) и «Модули». Пункт «Выбор раздела» в меню возвращает к нему. На узком экране карточки идут одна под другой.
- Рабочий стол показывает текущий приём, записи для проверки и повторные явки. Пустые состояния объясняют следующий шаг.
- Уточнены типографика, размеры полей, интервалы и состояния фокуса. Палитра: нейтральный светло-серый фон, белые формы и тёмно-зелёный акцент. Используются установленные шрифты Segoe UI; внешних шрифтов нет.
- Карточка, анамнез, осмотр и черновик получили согласованное оформление. Статусы «Черновик», «Проверено врачом» и локального сохранения остаются видимыми.
- С 0.25.0 «Мои сокращения» и Ctrl+Пробел убраны из интерфейса; сохранённые фразы остаются в данных.
- Существующие поиск, шаблоны осмотра и рекомендаций, личные сокращения, карточки, история и резервные копии сохранены.

## Клавиатура

| Сочетание | Действие |
| --- | --- |
| Ctrl+K | Поиск пациентов с выделением текущего запроса |
| Ctrl+S | Сохранение открытого приёма или карточки без смены места ввода |
| Alt+1…5 | Разделы открытого приёма |
| Tab / Shift+Tab | Следующий / предыдущий элемент |
| Стрелки вверх / вниз | Перемещение по главному меню |
| Стрелки влево / вправо | Переключение вкладок |

Поиск, сохранение и переключение разделов клавишами приостановлены, пока открыто диалоговое окно. Клавиши K и S распознаются по физической позиции, включая русскую раскладку. Ctrl+S не подтверждает медицинское содержание.

## Локальные данные

Правки сохраняются в хранилище текущего браузера. После перезапуска открывайте приложение тем же браузером и из той же папки. Для переноса и дополнительной копии используйте «Помощь и данные» → «Резервная копия». Очистка данных браузера или переход в другой профиль может сделать прежние записи недоступными.

Используйте только вымышленные сведения. Прототип хранит данные без шифрования, не подключён к МИС и не подготовлен для реальных медицинских записей. Черновик свободного текста не является нормативным медицинским документом Беларуси. Клинические решения интерфейс не генерирует; применённые шаблоны и итоговую запись проверяет врач. Отложенный разбор анализов из текста остаётся отключённым.

## Источники и пределы проверки

Изучены исходники `app/`, существующие тесты `tests/`, `ARCHITECTURE.md`, `START-HERE.txt`, `CHECKS.txt`, README поставки и продолженный чат «Install Web Design Skill».

Принципы оформления взяты из официального [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md), прочитанного 21 октября 2026 года. Локальная установка этого навыка не найдена; использован официальный текст инструкции.

Работоспособность проверяется на вымышленных данных в отдельном офлайн-профиле Edge. Медицинская корректность, соответствие нормативным формам Беларуси, работа с реальными пациентами и интеграция с медицинскими системами в эту проверку не входят. Результаты технических проверок описаны в `DESIGN-CHECKS.txt`.
