Добавить диагноз

После сохранения прежний текст диагноза останется отдельным основным диагнозом. При необходимости разделите его на несколько пунктов вручную.

Перед завершением приёма

Проверьте технические замечания. Содержание записи и необходимость заполнения сведений определяете вы. Текст не будет изменён автоматически.

    Пациенты в файле

    Добавить результат

    Выберите ОАК, ОАМ, БАК или другое исследование. В готовом бланке уже указаны показатели и единицы; для своего показателя выберите «Другое».

    Для динамики используйте одинаковое название и единицы.

    Необязательно для текстового заключения. Введите единицы так, как они указаны в бланке.

    Только из конкретного бланка, включая условия и пояснения. Если норм нет, оставьте поле пустым.

    Добавить бланк

    Перепишите только выполненные показатели. Строки без результата не сохраняются и не попадут в запись. Единицы можно исправить по бланку; нормы вводятся вручную.

    Изменение связанного результата вернёт проверенные приёмы в черновики. Сохранённый текст записи остаётся для вашей проверки.

    Исследования из карточки

    Отметьте результаты, которые нужно включить в этот приём и новый черновик. Снятие флажка убирает связь с приёмом; результат остаётся в карточке.

    Добавить препарат

    Все назначения и параметры вводит врач. Обязательно название; незаполненные параметры будут отмечены в списке и черновике.

    Мои шаблоны

    Своих шаблонов в этом разделе пока нет. Заполните раздел приёма и сохраните его под понятным названием.

    Содержимое выбранного шаблона

    Сохранить текущий раздел

    Новый шаблон создаётся из текущих полей приёма. Чтобы изменить сохранённый, отредактируйте эти поля, выберите шаблон и нажмите «Обновить выбранный».

    Формат записи

    Настройте следующий черновик. Уже написанный текст останется прежним. Настройки сохраняются в этом браузере и не входят в резервную копию карточек.

    Порядок разделов и подписи

    Повторный приём всегда остаётся в конце, после больничного.

    Программа использует ваши переносы строк, не разделяет предложения самостоятельно.

    Предпросмотр не меняет сохранённую запись.

    Личная заметка

    Видна в карточке и перед повторным приёмом. Не включается во врачебную запись. Сохраняется в резервной копии карточек.

    Чтобы удалить заметку, очистите поле и сохраните.

    Анализы из текста

    Вставьте результаты одного бланка и одной даты. Поддерживаются строки таблицы с табуляцией, точкой с запятой или разделителем |, а также строки вида «Гемоглобин: 130 г/л». Всё обрабатывается на этом компьютере.

    До 20 000 символов и 100 строк. Единицы и нормы берутся только из вашего текста.

    Проверьте и выберите строки

    Исправьте название, результат, единицы и нормы. Неразобранные строки можно заполнить вручную или оставить без отметки.

    Повторный приём

    Сводка собрана из сохранённых записей разных дат. Проверьте актуальность сведений. Просмотр источника ничего не переносит.

    Личная заметка · только для вас

    Не переносится во врачебную запись.

    Что перенести в новый приём

    Выберите исходный приём и отметьте нужные сведения. Перенос произойдёт только после нажатия «Создать приём». Пол, жалобы, осмотр, показатели, диагнозы, исследования и свободные рекомендации заполняются заново. Возраст рассчитывается по дате рождения из карточки; если её нет, укажите возраст вручную.

    При выборе другой записи отметки сбрасываются. Проверьте актуальность сведений.

    Назначения препаратов из выбранного приёма

    Каждое назначение переносится только по вашей отметке. Проверьте параметры и актуальность назначения.

    Источник сведений

    Только просмотр. Для переноса вернитесь к сводке и отметьте нужные сведения.

    Подключение кнопки обновления

    Закройте это окно программы и запустите МедАссистент через Start-MedAssist.cmd из той же папки. При запуске кнопка подключается автоматически. Если файлы запуска остались от версии 0.3 или 0.4, им требуется однократное обновление до 0.5. Инструкция находится в START-HERE.txt новой версии. До этого работает Update-MedAssist.cmd из вашей папки программы.
